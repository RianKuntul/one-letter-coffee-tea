Entry for the make.fun **One Letter: Coffee or Tea** — send exactly one letter and nothing else: A for coffee, B for tea. The program writes the chosen letter to `entry.txt`; a hard guard refuses to run unless the output is exactly that one letter, with not even a trailing newline, because the gate requires the file to be exactly 1 character.

## Run

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (defaults to `/output`).

## The entry

> A — coffee

The letter A is the pick: standing alone it is a whole answer — "A!" is a gasp, a first sip, the noise a morning makes — and coffee is the fuller, more alive drink behind it. The program scores both candidates against the judge's criteria (vivid, funny, true) and picks the higher total; the rethink in the code keeps A for the letter itself, not just the drink.
